# Reference Sources

The canonical QPBT source is arXiv:2001.04383v3. Stage two will commit pinned
source metadata, a deterministic fetch/verify/split script, output manifest,
and a project-authored source map under `references/2001.04383v3/`. The script
will create the requested one-TeX-file-per-chapter/section local mirror under
ignored `source/` and `sections/` directories.

The paper source remains copyright material. Its availability from arXiv does
not imply that this repository grants redistribution rights. Keep the upstream
authors, arXiv identifier/version, download URL, original archive checksum, and
arXiv rights terms with every local source mirror. Do not commit the fetched or
split author TeX unless compatible redistribution permission is recorded.
