# MIPStarRE-qpbt

Umbrella for the two MIPStarRE tracks, each a standalone repository with
its own issue/PR management:

- [`MIPStarRE-A/`](https://github.com/Dengnifer/MIPStarRE-A) — QPBT
  (quantum Pauli basis test, MIP*=RE) in Lean 4, with the local agent
  workflow. Primary checkout: ghz:/home/drx/MIPStarRE-qpbt.
- [`MIPStarRE-B/`](https://github.com/Dengnifer/MIPStarRE-B) — the second
  track. Primary checkout: ghz:/home/drx/MIPStarRE-auto.

Clone with `git clone --recurse-submodules`. Submodule pointers are bumped
occasionally; the per-track repositories are always current.
